Exif Puzzle — CTF Walkthrough

Extract the hidden flag from the image's comment metadata.

About this write-up. This is a short walkthrough: the original document is mostly screenshots, so all of its text is carried over here in full — the screenshots themselves could not be carried over. Nothing has been added to pad it out.

1. Why metadata?

The challenge description specifically says the secret is concealed in comment metadata. That makes metadata inspection the first step; there is no need to perform steganography or pixel analysis first.

2. Inspect the JPEG with ExifTool

On Kali Linux, place the image in your working directory and run:

exiftool whoami.jpg

ExifTool prints metadata fields stored in the JPEG. The field we care about is Comment.

3. Extract only the Comment field

To avoid unrelated metadata, query the comment directly:

exiftool -Comment whoami.jpg

The uploaded JPEG's comment metadata contains:

FlagFLAG{Ex1f_M3tad@t@_Ch@mp10n}

4. Submit the flag

Copy the value exactly as displayed, including capitalization, braces, numbers, and special characters.

FLAG{Ex1f_M3tad@t@_Ch@mp10n}

What happened technically?

JPEG files can contain metadata segments in addition to image pixels. One such segment is a JPEG COM (Comment) segment. The challenge author stored the flag there. ExifTool parses these metadata structures and exposes the embedded comment, so the flag can be recovered without modifying the image.

Quick command summary

Show only commentexiftool -Comment whoami.jpg
